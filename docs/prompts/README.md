# Cursor prompts (Waymark)

Use this folder for **saved Plan Mode prompts** and **small task prompts** you reuse.

- **[`MASTER_PLAN_PROMPT.md`](MASTER_PLAN_PROMPT.md)** — **full** Plan Mode prompt for roadmap / architecture (setup guide §18). Use when you need a **big** plan after bootstrap is done.  
- **[`PLAN_FIRST_SLICE.md`](PLAN_FIRST_SLICE.md)** — shorter Plan Mode kickoff for **one slice** at a time.  

Optional (create as you go):

- `IMPLEMENT_TODAY_SCREEN.md` — example small-scope implementation prompt  

**Rule:** One planning prompt → many small implementation prompts. Do not ask for the entire app in one message.

See **`docs/reference/waymark-full-stack-setup.txt`**, section **18) Cursor Plan Mode + master prompts**, for the full pattern.
